# Settings


Title on the top left. 
Under that is buttons anywhere from 2-4 depending on sepcs. Each of those icons is a spec for the class the player is currently logged into. 

The Current Active Spec is highlighted in blue. 

If a user toggles to another spec, it only updates the border color to blue not the whole box. Additionally the only thing shown under the left hand tree is the configured spells for that spec (those skills may not be active in the current specs CDm)

In that left menu at the top is two buttons. "Auras" "CDs". Blue highlight is the active one. 

When aura is selected. It will show a list of the current configurable auras (from the map). If a spell has been enabled or configured it is colored. If it is disabled or not configured, it is desaturated. It shows a large icon, with the name of the spell to the right (centered vertically on the icon to the right)

When you click a spellname the right hand side box updates with the following

 First Box: Enable, +Glow +Sound +Event

Under that is a list of current configured types (Glow, sound etc)

Each list item is named Type: Name (user defined name). If it is enabled is is colored blue. If not enabled it is grey. 

When you click on list item it expans with the options for that type. 

If you click any of the "+" buttons, it creates a new submodule of that type (glow, sound etc) and that sublist item is expanded (others collapse). 

Each Sub Modules (Glow, sound event etc) have an enable toggle to enable that specific instance. 

An example image of the general idea of it is settings.png in the root folder.
